# 体外循环术后管理 · 情境模拟教学 · 课前自学模块

面向 ICU 专科医师规培（PGY 2-3）的情境模拟教学课程，以一例体外循环（CPB）术后综合救治病例为主线。
本仓库只包含**学员端课前自学模块**，并通过 GitHub Pages 公开发布，供其他教师直接取用。

## 课程设计要点

- **Backward Design**：七个核心知识点均从病例的临床事件序列逆向提炼，每个知识点对应病例中至少一个关键决策节点。
- **Pre-Post 设计**：同一套题投放两次。前测记录基线（需求评估，INACSL 标准 2），自学后同题后测，达线方获得进入模拟的资格（标准 6）。两次测评目的不同，请勿要求学员跳过前测。
- **课程边界**：聚焦血流动力学与脏器保护的核心决策链，不覆盖心律失常、纵隔感染、气胸、神经并发症、瓣膜功能障碍。这是刻意的聚焦。
- 遵循 INACSL Healthcare Simulation Standards of Best Practice (2021)。

## 关于教员端材料

现场模拟决策工具、SOBP 教员剧本、KBA 评分表、PEARLS 复盘与 PAD 评估工具**不在本仓库内**。

这不是遗漏，而是模拟设计的必要约束：依据 INACSL 模拟设计标准 3，决策的时机与顺序、错误路径的真实后果、
评分指标与引导者线索台词必须保留至模拟与复盘阶段才披露。提前公开会使模拟丧失教学效度。

需要教员端全套材料的教师，请联系课程作者获取。
